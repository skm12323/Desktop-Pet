## 2. F2 正面骨骼

构建脚本：`tools/build_final_front.py --stage all`，按阶段依次执行 masks → labels → peel → completions → layers → eyes → spec → mesh，各阶段也可以单独运行。

| 环节 | 做法 |
|---|---|
| 切分 | SAM 3.1：概念提示 `prep/sam_parts_v1_text.json` + 点提示 `prep/sam_parts_v2_points.json`。文字提示漏掉了外层藏青裙、右袖、尾身、一只眼和一条腿，这些改用点提示。头发按几何区域分成 bangs（头框内）、hair_front（胸前发束）、hair_back_l/r。裙子和躯干用框兜底。袖口荷叶边、整只手、裙下尾身、围裙荷叶边按颜色补进对应层 |
| 分层 | `build_side_layers.py --plan prep/layer_plan.json`（本次新增 `--plan`，不传参数时与 ADULT 侧身方案逐像素一致）。共 16 层 + 眼部 4 层 = 20 层，47 骨（骨名与 ADULT 相同，由 motion.py 驱动） |
| 尾巴 | 尾鳍左叶和尾根被裙子遮住。用 Qwen 整条重画尾巴（绿底，`prep/peel/tail_redraw_s1.png`），配准后只填被遮挡处。新增 plan 规则 `edge_to_occluder`，把尾巴沿裙边的描边像素划给裙子，否则摆尾时会带出一条暗缝 |
| 手臂后方 | 用 Qwen「去掉双臂」做无遮罩编辑（`prep/peel/arms_removed_s1.png`），被手臂遮住的像素**按材质分类**（头发蓝 / 藏青布 / 白布）分给各层。不能按最近层分：编辑把裙子画窄了。其余区域用层内部颜色扩散填充：裙子只取藏青（亮度 <110），并限制在拟合的 A 字裙轮廓线内。否则会出现手形残影和黑色烟雾 |
| 眼睛 | SAM 点提示取虹膜，从 head_base 中挖出作为 pupil_l/r，原位置用眼白补；上睫毛复制成 eyelid_l/r，head_base 中保留，做法与侧身骨骼一致。head_base 被刘海遮住的部分只用肤色补，否则眨眼拉伸时会露出灰黑色带 |
| 眨眼区 | `blink_zones` 按睫毛顶到下眼睑测得。两眼只相隔 33 px，默认 25 px 的侧向带会重叠、导致挤压叠加，因此 FINAL 设 `blink_blend_px=10`（`mesh_generator.py` 新增此可选键，ADULT 不受影响） |
| 注视 | 虹膜按自身的静止轮廓椭圆采样，因此不会画到眼睑或皮肤上。`axis_limits_px` 设为 [4,3]，因为 FINAL 虹膜约 35×23 px，ADULT 约 45 px |
| 腿 | 只有小腿露在长裙外，所以腿链枢轴放在裙摆上方（y 1480/1640）。正面行走 14° 的大腿摆幅只会让鞋小幅挪动，不会把脚甩到侧面 |
| 尾巴骨 | 隐藏的尾根几乎不动（±1.5°），摆动集中在上卷段和尾鳍，避免尾根从衬裙下戳出 |
| 纹理 | 裁边后的原始 RGBA 共 9.6 MB，开启 mipmap |

## 3. 已知问题（不影响静止和空闲状态）

- 眨眼闭合时，左眼外角和两眼之间的刘海下方能看到网格拉伸出的竖直接缝。在 1824 px 画布上放大才看得出，256 px 窗口中约 1 px。
- 注视偏到极限时，虹膜边缘会出现椭圆裁切线。
- 关节打到 clamp 极限时（`extremes_sheet.png`），头 ±10° 会让后发补全区露出暗色，手臂 ±20° 时裙侧有补全色差。实际空闲幅度远小于此（头 ±0.3°，手臂只在行走时动 ±10°）。
- 正面行走个别帧右手旁有一个小碎点。
