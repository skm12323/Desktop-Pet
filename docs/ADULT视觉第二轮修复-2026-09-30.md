## 关键验证

衣身缺口的根因是 `build_side_layers.py` 只接受原图 alpha 等于 255 的遮挡像素。实测蝴蝶结和裙侧部分像素 alpha 为 252–254，补全图中已有正确内容，却没有进入最终图层。将内部遮挡判定改为 ≥240 后，三组压力姿态的最大真实材料缺口均从约 **3.87 降到 0.27 显示像素²**。静止复原平均误差为 **1.16/255**，通过原有 ≤6/255 门槛。

原检查把“刚形成的封闭背景区域”都当作缺口，误报了发丝环及手臂、衣裙之间的正常留白。新版检查沿缺口边界反查网格 UV 和可见材料：同一连续衣身/肢体内的缺口算缺陷，发丝环与不同部件间的留白单独记录；未知边界保守按缺陷处理。原始空白面积仍保留在 JSON 中。新增正反例测试验证了衣身内部缺口会失败、正常部件留白和发丝环不会误报。

实际会话、256 窗口、120 px/s 的纹理有效三角形统计：

| 层 | 最大局部拉伸：前 → 后 | 最小局部缩放：前 → 后 |
|---|---|---|
| 近侧腿 | 1.33 → 1.33 | 0.09 → 0.38 |
| 远侧腿 | 1.89 → 1.29 | 0.17 → 0.58 |
| 裙摆 | 1.96 → 1.38 | 0.70 → 0.84 |
| 尾巴 | 1.76 → 1.32 | 0.23 → 0.69 |

有效区采样均无翻折。统计要求三角形中心和三个内部点的原纹理 alpha ≥127；仍包含可能被上层遮挡的区域，不等同于整个部件的肉眼尺寸变化。全网格中尾部透明格子仍可能出现翻折，因此报告以有效区统计与实际渲染共同判断。

反向测试在三种停步相位下，等待 **3.53–3.75 秒 → 2.25–2.47 秒**；起步 **1.47 秒 → 1.23 秒**。取消反向后不会执行旧的左行意图。普通行走频率、落脚与鞋骨驱动保持原算法。

转身处理的青绿边缘候选像素计数约减少 **91%**：512 高片段 13910 → 1242，256 高片段 3856 → 351。判据只用于比较，剩余候选也可能是正常蓝色高光。只改 RGB；56 个受保护的端点/形变 PNG 与原文件逐字节一致。
