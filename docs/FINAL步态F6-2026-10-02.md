# FINAL F6 步态：长裙裙片驱动与小步幅

日期：2026-10-02　依据：`docs/FINAL侧身原画F3与长裙原型-2026-10-02.md`（B 结构已确认）、`docs/FINAL侧身骨骼F4-2026-10-02.md`。

## 改动

1. **裙片驱动接入 `pet/rig/gait.py`**（`GaitSolver._drive_panels`）
   - 配置读取 spec 顶层的 `skirt_panels`，包括骨名（后→前）、腰线 y、下摆 y、增益和弹簧参数。没有这个配置的骨骼（如 ADULT）行为不变。
   - 驱动方式：先用当前髋、膝角做正向运动学，得到小腿上 70% 处的点，算出它相对静止位置的前后位移。中段前半片跟随最靠前的小腿，后半片跟随最靠后的小腿（增益 0.6，3 Hz / 0.1 s 弹簧）。前、后两片按 0.6 倍跟随相邻片，弹簧更软（1.8 Hz / 0.18 s）。所有裙片绕腰线旋转，限幅 ±8°。
   - 与原型 B 的区别：小腿位置由 gait 内部的关节角直接算出，不再依赖渲染端的骨骼矩阵。
2. **步幅**：步频从 1.6 Hz 提到 2.2 Hz（速度不变，步幅 = 速度 ÷ 步频）。每个步态周期内鞋相对骨盆的前后行程从约 320 px 降到约 240 px，约 1.8 个鞋长；两脚同时着地时前后相距约 0.9 个鞋长，是长裙下的小碎步。
3. **接触点**：F4 自动检测出的鞋底长度只有 26 px（SAM 鞋掩码底部有杂行），改为人工测量的鞋跟、鞋底、鞋尖三点，鞋长 135 px。
4. **远侧鞋**：近侧鞋挡住了远侧鞋跟，迈步时露出的是残缺的鞋边。本地 Qwen 在紧裁剪的画面上整只重画了远侧鞋（`prep/peel/far_shoe_redraw_s2.png`）。第一次用宽裁剪，Qwen 画成了近侧那只带扣的鞋。重画图配准到远侧鞋可见部分（IoU 0.74），从鞋口以下整体替换。只把重画用在被遮挡区、可见部分保留原画的做法试过两版，迈步时鞋内都有接缝，已放弃。

## 静止复原门禁（需用户确认）

`spikes/qa_final_side_rig.py` 的静止复原在 256 显示下：平均 1.40/255（门限 6），**p99 50.05/255（门限 50，超出 0.05）**。破洞 0.06%，溢出 0.08%。

超出的原因是远侧手臂按你的要求整条换成了 gpt 重画，比原画粗，静止时必然和原画不同。这部分占全部差异的约 74%，远侧鞋整只重画约占 25%。排除远侧手臂重画区域后，平均为 0.41/255，p99 为 5.6/255。

ADULT 的做法与此相同：刻意重画的手部从破洞/溢出统计中排除（`qa_side_rig.py`，HAND_REDRAW）。我**没有**改变门禁判定：`pass` 仍按全图计算，所以当前显示不通过；排除远侧手臂后的数值单独列为 `excl_far_arm_redraw`。是否把这块刻意重画的区域从门禁中排除，请你决定。
