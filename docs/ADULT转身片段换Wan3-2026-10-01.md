# ADULT 转身片段换用 Wan 3.0 — 2026-10-01

## 背景

转身片段原先来自本地 Wan 2.2（480×848，16 fps），清晰度是转身段的上限。试过的其他方案：

| 方案 | 结果 |
|---|---|
| Seedance | 清晰，但把“转身”理解为整体匀速旋转，没有头→肩→胯的先后，弃用 |
| 本地 Wan 2.2 在 720×1280 | 4 步 LightX2V LoRA 在高分辨率下失效，转身中段出现叠化重影，弃用 |
| Wan 2.2 480p + 动漫超分（`tools/upscale_frames.py`，RealESRGAN_x4plus_anime_6B） | 线条更清楚、帧间最稳，但补不出新细节，未采用 |
| **Wan 3.0 API（阿里云百炼，`wan3.0-video`）** | 动作自然、无重影、原生 1080×1920，**采用** |

网页端的 Wan 3.0 带大水印；通过 API 调用时 `watermark=false`（默认值）输出无水印。

## 生成参数

`tools/wan3_flf2v_api.py`（key 只从环境变量 `DASHSCOPE_API_KEY` 读取，不落盘）：首尾帧为
`clips/endpoints/front_to_side_l160r40/{first,last}.png`，1080P、9:16、5 秒、30 fps、无音频、seed 1、
`prompt_extend=false`、`watermark=false`，提示词与 Wan 2.2 版相同。耗时 172 秒。完整记录（含提示词与文件哈希）见
`spikes/_qa/wan3_turn/wan3_1080_l160r40_s1.json`。原片 `clips/raw/wan3/*.mp4`（11 MB）按仓库惯例在 `raw/` 下，不入库。

## 后处理

```powershell
python -X utf8 tools/process_turn_clip.py assets/rig_adult_walk_v1/clips/raw/wan3/wan3_1080_l160r40_s1.mp4 `
  --endpoints assets/rig_adult_walk_v1/clips/endpoints/front_to_side_l160r40 `
  --first-ref assets/rig_adult_walk_v1/references/front_rest.png `
  --last-ref  assets/rig_adult_walk_v1/references/side_rest.png `
  --src-range 0:78 --duration 0.6 --motion-retime 0.35 --morph-frames 6 --hold-frames 3 `
  --height 512 --out assets/rig_adult_walk_v1/clips/turn_front_to_side
```

- 转身在原片前约 2.5 秒完成，之后是静止保持，故取 `0:78`。
- 转回正面用同一片段倒放：首尾参考图对调并加 `--reverse`。
- `--height` 取 256 / 512 / 1024，分别输出 `turn_*_h256`、`turn_*`、`turn_*_h1024`。
- 四个旧的 Wan 2.2 包在 git 历史中。

## 1024 高帧包与转身段变糊

高清参考 GIF 以 1024 高渲染骨骼，转身只有 512 高帧包，被放大 2 倍，进出转身时边缘锐度突降约 18%（551 → 451）。
默认 256 窗口不受影响（转身 141–152，静止 143、行走 154）。

- `pet/rig/presenter.py`：窗口高度 ≤320 选 `_h256`，≥768 选 `_h1024`，其余用 512 档；缺对应帧包时回退 512 档。
- 新增 `turn_front_to_side_h1024`、`turn_side_to_front_h1024`（各约 14 MB，解码约 57 MB，仅大窗口使用）。
- 重新导出的 GIF 转身段锐度 563（静止/行走 552）。

## 验证

场景 39/39，情绪与恢复 68/68，成年体骨骼 36/36，第二轮视觉 8/8，步态 8/8 与 2/2。首尾帧形变后与骨骼渲染差 0/255。
运行这些测试需用 Python 3.12（PySide6 6.11）并设 `QT_QPA_PLATFORM=windows QT_QUICK_BACKEND=rhi QSG_RHI_BACKEND=d3d11`。

## 遗留

- 512 档帧包解码内存 14.6 MB，仍超过 12 MB 的单条门禁（旧包同样超出）。
- 帧包只逐帧检查了关键帧；转身中脚底是否滑动、尾鳍形状是否稳定需要在真实桌宠里再确认。
