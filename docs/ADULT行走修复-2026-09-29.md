## 2. A：权重与网格

**改动**（只对显式配置的层生效；不带新字段的层——正面 rig、YOUNG——走原算法，已验证正面 rig 用新旧生成器重生成结果完全相同）：

- `tools/mesh_generator.py`
  - `weights.mode = "chain"`：父→子骨链，每个顶点归属最近链段的骨骼，只在关节二等分线两侧 `blend_px` 内与相邻骨过渡（用最近链段而非无限切线，卷曲的尾巴不会被远处关节误切）。
  - `weights.inner`：单向铰链（膝、肘、踝）的**内侧**（屈曲侧）加宽过渡带，按顶点到链轴的横向距离渐变；过渡主要伸入**父段**（`blend_px`），子段只伸入 `down_px`，使小腿保持笔直。
  - `weights.mode = "skirt"`：腰带归裙根，下摆按高度渐入、按前后分给两根裙摆骨。
  - `min_component_px`：小于阈值的碎片不生成网格单元（不再被骨骼拖着走）。
- `tools/build_side_spec.py`：侧身各层配置（腿/臂网格 14 px，裙/尾 20 px）；spec 透传 `weights / grid_step / min_component_px`。

**调参过程（关键发现）。**

1. 窄过渡带（26 px）在步态中膝窝翻折：膝盖弯到 25° 即翻。
2. 试 2D 对偶复数蒙皮（DQS）——**无改善**（翻折是绕支点的扫掠，不是弦塌缩），已撤回运行时改动。
3. 真正原因：**膝关节支点在腿的前缘**（x 464，腿在该高度 x 390–473，距膝窝 ≈ 87 px）——为让 IK 静止时解出前向膝而刻意前移（画上的腿是锁膝微反弓站姿，膝中心在髋–踝连线后 15–27 px）。移到中线需要改造 IK 与锁脚，故保留支点，改用内侧加宽过渡带吸收膝窝褶皱。
4. 内侧宽度随横向位置变化过陡会在大腿后侧剪切翻折；子段完全刚性又会把扫掠集中到关节线、更早翻折；子段延伸过长则小腿中线弯曲（round2"小腿笔直 ≤ 8°"门禁）。网格搜索（仿真膝弯 0–90°）+ 正式门禁复核后定为：膝 `blend 22 / inner 110 / down 60 / ramp 80`（两腿相同，仿真 70° 起才翻折），踝 `28 / inner(前侧) 60 / down 28`，肘 `18 / inner(前侧) 80`；hair_back 碎片阈值 40 px（200 px 会删掉一块静止可见的 43 px 发丝，造成静止空洞）。

## 3. 变形算法改进（计划 `rippling-orbiting-flurry`：推导 D1–D7 与按形状分配的变形器）

A 之后的深挖结论：单块连续网格在铰链处弯曲，det F = 1 + θ·|∇w|·ℓ（DQS；LBS 一阶相同），支点居中且不翻折时外侧峰值拉伸 ≈ 2——A 把分散扭曲换成了集中扭曲（leg_r σmax 2.18、arm_r 1.98），属结构上限，调参不可越过。改为按形状分配：铰链肢体 = 分段刚体 + 圆盘关节盖；尾/发 = 中心线曲线 + 绳索；裙/围裙 = 笼形 MVC + 覆盖约束；躯干保留链式权重。

**阶段 0 度量工具** `spikes/qa_deform_metrics.py --tag <名>`：步态（120/200 px/s，256 窗口）与人类范围压力姿态（膝 65°、髋 +30/−15、肘 45°）下的翻折、每层 σmax/σmin、网格焊接；结果存 `spikes/_qa/deform_metrics/<名>.json`。

## 4. 正常人行走参考数据（步态重设计 C 的依据，2026-09-29 检索）

来源等级：**[一手]** 可读原文的实测；**[教科书]** Perry & Burnfield《Gait Analysis》、Winter《Biomechanics and Motor Control of Human Gait》中被广泛引用的典型值（本次检索只拿到二手转述，未读到原书表格）；**[二手]** 综述/网页转述，未核对原文。

### 4.1 下肢矢状面（屈为正；一个步态周期从同侧脚跟着地开始）[教科书]

| 事件（% 周期） | 髋（相对骨盆） | 膝 | 踝 |
|---|---|---|---|
| 着地 0% | 屈 ≈30° | ≈0–5° | ≈0° |
| 承重反应 ≈10–12% | ≈30° | **屈 15–20°（支撑期缓冲峰）** | 跖屈 5–10° |

| 摆动中期 ≈70–75% | 屈向 30° | **屈 60–65°（峰）** | 回到 ≈0° |

### 4.2 上肢

- 肘屈伸活动范围 **29.7° ± 10.2°**（15 名健康成人，1.11 m/s）[一手] ([Cho et al., CiSE 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10277704/))；行走中肘**始终微屈**，前摆时屈曲增大。
- 肩（上臂相对躯干）矢状面总摆幅约 30–40°，约伸 20–30° 到屈 5–15°，即围绕略靠后的位置摆动，速度越快摆幅越大 [二手]。
- 相位：常速下手臂与**同侧腿反相**、频率 1:1（很慢时变为 2:1 且两臂同相）[二手，([Meyns et al. 2013](https://pubmed.ncbi.nlm.nih.gov/23489950/))]；手臂摆动大部分是被动的，由躯干运动带动 ([Collins et al. 2009](https://royalsocietypublishing.org/doi/abs/10.1098/rspb.2009.0664))。

### 4.3 关节之间的关系（动作"自然感"的关键）

1. **着地前腿伸直**：摆动末期大腿先到最前（≈85%），膝随后伸到近 0°，脚跟以接近直腿着地。
2. **承重反应屈膝**：着地后膝立即屈 15–20° 再伸回（缓冲），此时髋基本不动——这是"有弹性"的来源。
3. **支撑期直腿过渡**：支撑中期膝接近伸直，身体越过支撑脚，骨盆达到最高点。
4. **离地前先屈膝**：髋还在伸展时膝已开始屈（摆动前期 35–40°），脚跟先抬起、脚尖最后离地。
5. **摆动期单峰**：膝在 ≈70% 达峰（早于髋屈峰 ≈85%），髋单调前摆，**不回退**。
6. **手臂**与对侧腿同向（与同侧腿反相），肘始终微屈，前摆时更屈。
7. 骨盆每步起伏两次：支撑中期最高、双支撑最低，幅度约为腿长的 5%。
