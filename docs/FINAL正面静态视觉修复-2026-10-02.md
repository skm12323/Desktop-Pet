日期：2026-10-02。基于 `8e59cfb` / v0.16.16 的视觉审查。本轮保留用户选择的各情绪原有姿态，统一可见大小和脚底；没有把全部情绪改成中性站姿。

| 项目 | 实施结果 |
|---|---|
| 待机贴地 | 将 ADULT 的落地整体浮动、漂移和骨盆呼吸约束扩展到 FINAL。上身呼吸、尾巴、头发和离地运动保留。320×320 下 150 个待机帧的鞋底固定，原先 62 帧裁切降为 0 帧。 |
| 旧分层静态接缝 | 清理 neglected_neutral 头发与裙摆的可见扩展残留，恢复原画材质颜色，修正重叠部件和核心图的透明度分配。零角度合成的 alpha 最大误差为 1/255，超过 32/255 的 alpha 失配为 0；没有增加豁免区或放宽阈值。 |
| 情绪显示大小 | 按可见 alpha 轮廓缓存显示范围，十种状态使用同一目标高度并贴窗口底边。源图姿态保留；动作帧使用原有取景。健康中性仍使用蒙皮，其余情绪保留整图或旧分层渲染。 |
| 眨眼与注视 | 虹膜采样改为真实眼眶开口，网格边界覆盖完整像素单元。睫毛只保留一份移动描边，修正混入眼睑的发丝和抗锯齿边缘；眼白和肤色分别从对应材质取样。细化眼部网格，约束脸部切缘，避免轮廓被眨眼拉长。闭眼眼白检查及连续睁眼恢复通过。 |
| healthy/hungry | 直接调用内置 `image_gen.imagegen`，替换 `assets/ai/final_healthy_hungry.png`。修复绿眼、圆张嘴和惊讶感，保留持碗、持筷的进食姿态及整体角色特征；输出 1024×1536 RGBA，保留工具生成的真实 alpha。完整提示词、参考图和输入/输出哈希记录于 `assets/ai/final_healthy_hungry.imagegen.json`。 |
