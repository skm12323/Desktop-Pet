> 与 `设计思路.md` 配套。每版是一个**可验收里程碑**。
> 修订：v0.0.3 整合设计师评审 + 项目总监评审反馈。
> 修订：v0.0.7 同步双平台协作（双侧并行开发）与 UI 分层（应用型界面走 QML）。
> 修订：v0.0.8 项目总监审查——各版补交互/气泡/持久化/全屏/活跃检测/打包Spike/浸泡测试。
> 修订：v0.1.1 清理失效的 `Windows适配计划.md` 引用（已并入 `平台适配与分工.md`）；平台专属 API/路径 中立化或并列双端；win 端强制吐出热键定为 `Ctrl+Alt+T`。
> 修订：2026-08-27 增补 **v0.13.0 分层绑骨渲染器（丝滑展示层）** 条目（用户批准的展示升级，区别于既有规划的新增工作）；实施顺序依 §0.1 排序原则可调——经与用户确认先行于打包（下方 v0.12 段保持内容不动，届时按实际执行序推进）。

## 0. 总则

### 0.1 排序原则
差异化前置（养成/物理）+ 技术风险前置早 de-risk（透明窗口 / DS / CGEventTap / AI 立绘）。版本顺序可调，但每版验收的 **Must 项不可妥协**。每版 Must 需 **macOS 与 Windows 各自达成**（双端适配项、平台路径与风险 Spike 见 `平台适配与分工.md`）。

### 0.2 技术风险清单（高风险项，对应版本前必须有验证结果，否则不进下一里程碑）
| 风险 | 验证版本 | 验证物 |
|---|---|---|
| 透明窗口 Mac 兼容性 | v0.1 | 透明置顶浮窗上屏 |
| DS function calling 稳定性 | v0.4 | 多轮对话+工具调用跑通 |
| 鼠标抑制 + 安全解锁（mac CGEventTap / win WH_MOUSE_LL） | Spike(v0.7前) + v0.7 | 抑制+看门狗5s释放 |
| AI 图像生成方案可用/成本/质量 | Spike(并行,不占版本号) | 静态图可生成且去背 |
| 窗口枚举性能 | v0.3 起监控 | 不每帧枚举，CPU 达红线 |

### 0.3 质量门（每版合入前）
- 核心模块单元测试：`PetStateStore`、`BehaviorFSM`、`ToolRegistry`、`memory.py`（按版本到位情况）
- 关键路径集成测试：DS 工具调用、吃鼠标安全解锁、进化分支
- 物理边界测试：不穿屏、不飞出
- 合入前跑快速回归（防 v0.3 物理改 `screen_pos` 连累养成数值）
- 性能基准：`psutil` 抽测 idle CPU / 内存达红线（§一）
- **24h 浸泡测试**（v0.3 起每里程碑）：`python app.py` 运行 24h，结束后 `psutil` 内存 ≤ 200MB、进程无崩溃、日志无异常。`--verbose` 模式下可选 `tracemalloc` 内存快照辅助排查。

### 0.4 Must / Should 分级
- **Must**：核心功能、安全、性能基准、接口契约——不可妥协。
- **Should**：体验优化、可配置项、后台运行等软性目标——允许记为已知限制后续补。
- 软性标准（如"可前台运行"）只进 Should，不进 Must。

### 0.5 内部可运行验证
每里程碑至少产出**可通过 `python app.py` 跑起来**的内部验证，风险前置消化；正式 `.app` 打包仍 v0.12。

### 0.6 里程碑评审
每版完成后做一次约 15 min 验收评审，确认 Must 全绿再进下一版，避免"后面一起补"。

### 0.7 并行 Spike（不占正式版本号）
- **S0 AI 立绘 Spike**：v0.2 完成后启动，验证图像模型 API（即梦/SD/其他）可用性/成本/质量/去背，产出结论供 v0.10 接入选型。不阻塞主线版本。
- **S1 CGEventTap Spike**：v0.7 开发前启动，验证鼠标抑制 + 看门狗解锁，产出可复用代码骨架。
- **W1 透明穿透 / W2 鼠标钩子 Spike（Windows 侧）**：见 `平台适配与分工.md` §六，分别于 v0.1 前、v0.7 前启动。
- **S2 打包 Spike**：v0.5 完成后启动，用最小功能集（透明窗+emoji+拖拽）试跑 py2app + PyInstaller，提前发现并解决 bundle 内 QML/assets 路径、keyring 后端、codesign 等问题。不阻塞主线版本。

## v0.1.0 上屏（透明浮窗 + emoji 立绘 + 底边行走）

**目标效果**：启动后桌面底边出现一只 emoji 小东西，透明置顶，随机溜达两步，托盘能退出。

**工作内容**
- `pet/window.py`：PySide6 frameless 透明置顶浮窗
- `pet/bubble.py`：`BubbleWidget` 骨架（能显示文字，v0.2 起接入养成/主动关怀/LLM）
- `pet/asset_provider.py`：`AssetProvider` 接口（**`get_static` + `get_frames` 双方法 + `SpriteRef`（含 width/height/anchor），v0.1 即冻结**）+ `EmojiProvider`
- `pet/behavior.py`：`ActionType` Enum + `BehaviorFSM` 骨架（`idle` + `沿底边随机走`）
- `pet/tray.py`、`pet/config.py`（DS key 占位）、`pet/logging_setup.py`（日志地基）
- `app.py`（`--verbose` + **单实例锁** + `shutdown()` 退出清理骨架）
- 交互手势 hook：`window.py` 中 `mousePressEvent`/`mouseReleaseEvent`/`mouseMoveEvent` 预留位移+时长计算（空实现），v0.2 填入单击/双击/右键，v0.3 填入拖拽

**验收**
- Must
  - [ ] `python app.py` 前台启动，窗口透明、无标题栏、置顶
  - [ ] 角色以 emoji 显示在底边工作区（mac `NSScreen.visibleFrame` / win `QScreen.availableGeometry()`），尺寸按 `SpriteRef` 锚点 `bottom_center`
  - [ ] 30 s 内至少一次自主位移
  - [ ] 托盘"退出"能干净退出，无残留进程（走 `shutdown()`）
  - [ ] 日志写入平台日志目录（mac `~/Library/Logs/Desktop-Pet/` / win `%LOCALAPPDATA%\Desktop-Pet\logs\`）
  - [ ] **单实例锁**：重复启动 → 唤醒已有实例，不产生第二个进程
  - [ ] **气泡骨架**：能调用 `BubbleWidget.show(text)` 显示文字气泡
- Should
  - [ ] 关闭终端后进程不随之死（后台运行），允许记为已知限制

## v0.3.0 桌面物理（拖拽抛掷 + 重力 + 跟随鼠标 + 随机游走）

**目标效果**：能抓起来扔出去，抛物线掉回底边；能跟随鼠标；会自主全工作区随机游走；偶尔伸懒腰/打滚。

**工作内容**
- `AssetProvider.get_frames` 实现（动作帧序列）
- `BehaviorFSM` 扩展：`dragged`/`thrown`/`falling`/`follow_cursor`/**`WANDER`（全工作区随机游走）**/`random_idle`
- **WANDER**：工作区内随机选目标点 → 行走过去 → idle 随机时长 → 选下一点，循环；尊重重力（地板/窗口顶面走，跨表面掉落）；频率受养成数值调制（心情高更爱游走）
- 拖拽抛物 + 触底停止；跟随鼠标模式；idle 随机小动作
- **窗口枚举缓存**（事件驱动 / ≤2s 刷新，不每帧）
- **全屏/演示模式检测**：mac `NSWorkspace` 通知 + `CGWindowListCopyWindowInfo` / win 前台全屏应用检测（见平台文档），全屏时自动隐藏/移副屏、暂停 WANDER；演示模式（Keynote/PowerPoint 前台全屏）完全隐藏 + 禁吃鼠标
- 边界测试：不穿屏、不飞出

**验收**
- Must
  - [ ] 按住拖动跟随指针
  - [ ] 释放带初速度走抛物线，落到底边停止，不穿屏不飞出
  - [ ] 跟随鼠标模式朝指针移动
  - [ ] **WANDER：空闲时自主游走至工作区随机点，到达后 idle 再选下一点，不卡死不重复同一点**
  - [ ] 1 min 内至少一次随机小动作（`get_frames` 出帧）
  - [ ] 物理只改 `screen_pos`，不碰养成 state（接口隔离）
  - [ ] 窗口枚举不每帧，idle CPU 达红线
  - [ ] 物理边界测试绿
  - [ ] **全屏检测**：打开全屏视频/Keynote → 宠物自动隐藏或移副屏，退出全屏自动恢复

## v0.7.0 吃鼠标（鼠标抑制 + 安全铁律 + 最小权限引导）

**目标效果**：久坐该休息且空闲时，宠物吃掉你的鼠标——但随时能吐出来，重要时段/活动中不打扰。

**工作内容**
- **前置 S1 / W2 鼠标抑制 Spike**：mac 验证 CGEventTap、win 验证 `WH_MOUSE_LL`，含看门狗解锁
- `EatMouseSession`（`start`/`force_spit`/`on_dnd_active`）+ 平台鼠标抑制（mac `CGEventTap` / win `WH_MOUSE_LL` 钩子+钉光标）
- **看门狗线程**：主逻辑崩也 5 s 自动释放
- `BehaviorFSM` 加 `EAT_MOUSE` 状态，`ProactiveScheduler` 发事件切换；动画由 FSM 驱动
- 安全铁律：只锁鼠标不碰键盘 / 超时≤15 s / 强制吐出热键：mac **`Cmd+Option+T`**（T=吐；弃 `Cmd+Option+Esc` 系统强制退出冲突，原 `Cmd+Option+Shift+P` 4 键难按）、win **`Ctrl+Alt+T`**（T=吐，与 mac 对应；避开 `Ctrl+Alt+Del`），+ 托盘菜单 / **idle gate**（`idle_time<5min` 只气泡）/ DND 白名单
- **活跃内容检测**：吃鼠标前额外检查前台应用是否为视频播放器（白名单，如 mac IINA/QuickTime、win Films&TV/PotPlayer/浏览器全屏视频），命中 → 只气泡不吃鼠标。白名单进 config 可扩展
- **权限最小引导**（从 v0.8 提前到这版）：mac Accessibility 检测，未开给提示 + 跳系统设置入口；win 运行时自检钩子可用性。权限未开/钩子不可用时只提示不抑制
- 养成回血：+饱食/+心情
- 集成测试：吃鼠标安全解锁（含看门狗）

**验收**
- Must
  - [ ] 休息提醒 + `idle>5min` 双条件触发吃鼠标，鼠标被抑制（win 管理员窗口场景除外：UIPI 限制 → 降级只气泡，有日志）
  - [ ] **键盘始终可用**，Esc/热键能立即解锁
  - [ ] **看门狗**：主逻辑崩溃后 ≤5 s 自动释放
  - [ ] 强制吐出热键 + 托盘菜单均能立即释放
  - [ ] 单次锁定 ≤15 s 自动释放
  - [ ] DND 开启时不触发吃鼠标，只气泡
  - [ ] `idle<5min` 时只气泡不吃鼠标
  - [ ] **活跃内容检测**：前台播放视频（白名单应用）→ 即使 idle>5min 也只气泡不吃鼠标
  - [ ] mac Accessibility 未开 / win 钩子不可用时明确提示 + 跳设置，不抑制
  - [ ] 吃鼠标后饱食/心情上升
  - [ ] 安全解锁集成测试绿
- Should
  - [ ] 完整权限向导 UI 留 v0.8 完善
