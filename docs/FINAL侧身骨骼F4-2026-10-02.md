## 1. 做法

| 环节 | 做法 |
|---|---|
| 切分 | SAM 3.1 分两轮：原型轮（`prep/sam_parts_proto.json`）和 F4 轮（`prep/sam_parts_f4.json`）。头框内的头发归 bangs 层，压在眼睛上的发丝也按颜色归入 bangs，放在眼睑之上，避免眨眼时被挤弯。远侧头发归 hair_side_r。腿以裙摆为界，裙摆以下逐像素分给最近的鞋。尾巴外圈 8 px 不归裙子：否则摆尾时尾巴的描边会留在裙上，变成一圈铁丝样的线 |
| 远侧手臂 | 本地 Qwen 在绿底上整条重画（`prep/peel/far_arm_redraw_s1.png`）。SAM 点提示抓到的是围裙荷叶边，所以改为按颜色对齐重画图，用重画轮廓确定手臂归属。原画中露出的窄条也划归手臂，否则摆臂时躯干上会留下第二条袖子 |
| 近侧手臂后方 | Qwen「去掉近侧手臂」编辑（`near_arm_removed_s1.png`）。被遮像素全部采用编辑后的颜色，只按材质决定归层：浅蓝头发归后发，深色衣物按腰线分给躯干或裙子。用扩散填充的话，摆臂后会留下手臂残影 |
| 尾巴 | 只用 Qwen 整尾重画中的尾鳍部分：它与原画尾身弯法不同，整条配准只有 IoU 0.58，单配尾鳍为 0.80。被头发和手挡住的右叶由重画图补出。尾根伸进裙下的部分按行外推。整个尾鳍（含右叶）设为刚体 |
| 腿 | 隐藏的长袜柱从髋连到踝，只在裙摆被抬起时才会露出。权重沿用 ADULT 的做法（窄髌骨带、宽腘窝带、joint_curve） |
| 长裙 | 4 片裙骨（back / mid_b / mid_f / front）都挂在腰线上，权重由 `_panel_weights` 写入，结构同原型 B。gait 的 `skirt_follow_gain=0`，裙片驱动留到 F6 接进 gait.py。步频 1.6 Hz |
| 眨眼 | `blink_zones` 从睫毛顶量到下眼睑。若上界取低了，睫毛上方的粗线会被拉成黑块。眼睑层只取紧贴眼睛的睫毛，不含虹膜顶部。远侧眼距脸颊轮廓仅 20 px，侧向带取 6 px |
| 补全 | 只从层内部取色，防止描边被涂开。裙子只取藏青色，并限制在拟合出的 A 字裙轮廓内。被刘海遮住的脸只用肤色补 |

本地生成全部串行执行，每次一张：远侧手臂、去近侧手臂、整尾三张 Qwen，加两轮 SAM。ComfyUI 已关闭。

## 3. 已知问题（F6/F8 视觉轮处理）

1. 近侧手臂向后摆到极限（20°）时，原位置露出的是 Qwen 编辑出的背面蝴蝶结和衣褶。上段可以接受，手腕高度一带有少量模糊和白色发梢碎片。
2. 腿部极限姿态仍有翻折，集中在膝窝和鞋跟。正常步幅下未见；步幅在 F6 会收小。
3. 尾巴、头和头发同时打到 clamp 上限（tail_head 姿态）时，尾鳍根部有少量翻折，发尾间隙也会扩大。待机幅度下尾巴干净。
4. 闭眼时，近侧眼上方被拉伸的皮肤偏亮（刘海下的补色是模糊的）。在 256 窗口里很难看出。
5. 裙片整体前摆 4° 时，前缘与远侧手、围裙之间会形成一块被包围的背景。这是轮廓变化造成的，F6 调驱动增益时一并看。
