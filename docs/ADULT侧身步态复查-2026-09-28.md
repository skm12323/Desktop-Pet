# ADULT 侧身步态复查与接入（2026-09-28）

已将 `adult_locomotion` 默认值和本机配置设为 `side_rig`。旧配置缺少该字段时也会接入侧身行走；显式 `legacy` 和资产缺失回退仍保留。本机配置已另存 `config.json.before-side-gait-20260928`，已运行的进程需要重启加载代码及配置。

## 定位及修正

1. **膝盖反折**：原求解器固定选择屏幕左侧的 IK 解，而资产朝向右侧。实际渲染骨骼的膝盖位于髋踝连线后方 9–22 px。侧身包改用朝前的解，同时校正膝关节静止位置、屈曲限位并重建蒙皮权重；旧正面包保留原解。
2. **身体下沉过大**：原骨盆高度由静止腿长代替当前踝部高度计算，抬脚时仍强制下蹲。改为根据当前髋踝几何计算，侧身支撑伸展率改为 0.985，完整步态周期频率从 1.2 Hz 调至 1.6 Hz，缩短单步跨度。
3. **停步后横向拖脚**：停止状态只冻结最后落点，随后呈现层将骨骼角度直接归零。增加 `walk_park`：一只脚支撑，另一只脚抬起、收回原站位、落地；双脚回位后再恢复直立姿态。接入转身前不再依靠两脚同时横滑归位。
4. **高速起步滑脚**：落脚点按起步瞬间速度计算，漏算摆动过程中身体加速的位移。补上加速预测，并在跟随速度下提高步频，防止持续加大步幅。

## 第二轮复查（Claude，2026-09-28）：小腿反弯与停步怪异

证据：`spikes/_qa/side_gait_review2/walk_cycle_legs.png`、`stop_legs.png`（画布级渲染，腿部放大）。

### 问题

1. **小腿反弯（行走中）。** 上一轮为防止"腿根横移"，给两条腿加了骨盆锁定 `root_lock`：源画布 y ≤ 1100 完全绑定 `root_hip`，1100–1400 平滑过渡回腿骨。膝关节在 y ≈ 1215–1225，处在过渡带内（root_hip 权重：1150–1200 为 0.84，1200–1250 为 0.60，1250–1300 为 0.38，1300–1350 为 0.19）。结果大腿几乎不随大腿骨转动，腿骨与骨盆的交接落在小腿中段，形成"第二个假关节"。实测一帧行走（骨骼要求：大腿 −21.6°、小腿 +8.3°，只在膝盖弯一次）的网格中线：大腿 −32°、膝下 −27°、**小腿中段 +18°**、小腿下段 −32°，呈 Z 字折。
2. **停步怪异（约 1.1 s）。** 求解器轨迹（停步指令后）：
   - 最后一步把前脚（近侧 L）落在静止站位前方约 200 canvas px（约 30 显示 px）；
   - 随后两只脚都停在滚动中途约 0.3–0.6 s：前脚踮脚（后跟抬起约 30°，FOREFOOT），后脚后跟着地、脚尖翘起（约 −9°，HEEL）；
   - `walk_park` 再把**前脚向后**迈回站位（x 679 → 475），越过另一只脚——双腿交叉成 X、两只鞋叠在一起。
3. **远侧鞋跟黑块。** 远侧鞋被近侧鞋挡住的后跟用邻色块填充（`side_completions.py` 的 box/poly），脚一倾斜就露出一块黑色方片。
4. **测试缺口。** 现有门禁没有：实际网格"每条腿只在膝盖弯一次"、停步"不后退、不交叉、不长时间保持踮脚/翘脚尖"。另外 `test_adult_turn_gait.py` 仍断言 11 个步态状态，新增 `walk_park` 后该项失败（契约过时，不是行为回归）。

### 方案（用户已同意，第 1 项由 Claude 自行选择做法）

1. **小腿：** 骨盆锁定只保留在裙下看不见的部分，在裙摆荷叶边后面（约 y 1100 → 1160）结束，膝盖与小腿完全由腿骨驱动，只在膝盖处弯曲。腿根在裙下的少量横移由裙摆跟随大腿摆动（裙摆骨骼按大腿角驱动）来遮盖，而不是把腿钉住。
2. **停步：** 刹车时按身体最终停止位置规划最后一两步，让每只脚直接落在自己的静止站位；若仍需收脚，只允许后脚向前收，不允许向后迈、不允许交叉；停顿前脚掌放平，不保持踮脚/翘脚尖。
3. **鞋跟：** 用近侧鞋的后跟形状（或 Qwen 单独重画完整远侧鞋）替换黑色色块，保证倾斜时形状正确。
4. **测试：** 新增网格级"单关节弯曲"、停步"不后退/不交叉/无长时间踮脚"检查；更新 `test_adult_turn_gait.py` 的状态集合契约（加入 `walk_park`）。

### 第二轮修正结果（Claude，2026-09-28）

1. **小腿反弯 → 已修。** 删除两条腿的骨盆锁定（`build_side_spec.py`），整条可见腿只由腿骨驱动；腿根在裙下的前后摆动改由裙摆跟随大腿（`gait.skirt_follow_gain = 0.8`，前缘角 = 增益 × 最前大腿角、后缘 = 增益 × 最后大腿角；裙摆骨支点上移到 (660,900)/(380,900)、限位 ±20°，否则前缘支点在裙角上、转动推不动裙角，远侧大腿前摆时会从裙角露出一条皮肤）。近侧膝支点 468→464：膝支点必须在髋–踝连线（y1225 处 x≈459）之前，否则前向 IK 在静止时就被解成镜像膝。另发现并修正：静止腿长达全长 99.99%，IK 软收缩带（0.5 px）把静止姿态解成膝多弯 4°——`Analytical2BoneIK.solve` 新增 `exact_within`，髋踝距 ≤ 静止距离时精确求解（静止姿态所有骨角 = 0，片段→侧身接缝恢复到 ≤ 1.45/255）。
2. **停步怪异 → 已修（`gait.py` WALK_PARK 重写）。** 摆动脚一落地就收步（不再等包络衰减 → 无踮脚/翘脚尖停顿）；支撑脚绕各自接触点放平；若有脚领先站位，身体（窗口）平滑前移到该脚上方（双脚锚定，不滑）；仍落后的脚依次向前迈到站位（世界系插值，严格向前；大偏差 0.30 s、小偏差 0.22 s 低抬的小调整步），第一步与前移并行开始；停步最后一步直接落到"前移后的站位"（不再与另一只脚叠在一起）；收步结束直接把站姿交给静止放平（无闪回帧）。结果：指令后约 1.0 s 静止（原 ~2 s），最终站姿与静止站姿差 ≤ 0.05 canvas px。
3. **远侧鞋跟黑块 → 已修。** `side_completions.py` 新增 `copy` 方法：用近侧鞋自己的后跟（同款鞋）缩放 0.95、对齐后跟底角，填远侧被挡住的后跟；`build_side_layers.py` 丢弃补全中 < 30 px 的游离碎片。另：Qwen "去掉围裙"剥层（`prep/peel/apron_edit_s1.png`）替换围裙下方裙子/衣身的邻色填充（裙摆随腿摆动时围裙边缘不再露出黑色涂抹）。
4. **测试。** 新增 `spikes/test_side_gait_round2.py`（8 项）：网格级单关节弯曲（小腿各段方向差 ≤ 8°、网格膝角 = 解算膝角 ± 10°，按真实三角形重心插值测中线）；停步 3 速度 × 3 时刻 × 30/60/120 Hz/抖动：静止 ≤ 1.6 s、抬起的脚不后退、放平后无踮脚、最终站姿、膝角速度 ≤ 20 rad/s、接触漂移 ≤ 0.5 px。`test_adult_turn_gait.py` 状态集合契约加入 `walk_park`；`test_side_gait_naturalness.py` 的"腿根钉在骨盆 < 1 px"断言改为"腿根顶点始终被变形后的裙子网格覆盖"（新设计）；`test_adult_locomotion_app.py` 行为层滞后上限改为两个 50 ms 拍（计时器抖动，真正的拉锯检查另项）。

### 第三轮（Claude，2026-09-28）：腿偏前、手臂僵直

**诊断。** 行走时两脚平均落点其实比静止站位还靠后（踝比原画后 14 canvas px），但大腿平均前倾约 −10°：行走下蹲（支撑腿伸展率 ≤ 0.985）+ 膝盖向前弯，把膝盖/大腿推到身体前方，看起来腿走在身体前面。手臂：上臂 ±12° 整臂摆动、前臂只在前摆时弯 0–8°，后摆时整条手臂笔直；而四分之三视角下整臂绕肩转 16° 会把手甩到身体外侧（像张开的钟摆）。

**修正（`gait.py` 新增可选项，旧包缺省不变；`build_side_spec.py` 设值）：**

- `track_offset_px = −30`：行走时落脚点整体后移（随速度渐入；高速按 120/v 缩小，否则 200 px/s 时后腿离地前接近伸直、膝角速度超标）；停步最后一步不后移，收步仍只向前。
- `toe_off_end_deg = 35`：趾离地段脚跟不再从 35° 回落到 18°。回落会让踝下沉、后腿在离地前一瞬被拉直、膝角一帧回弹；真实步态离地时脚跟继续抬起。
- `torso_lean_deg = 3`：行走时上身（spine）前倾 3°，上身压在腿上方。
- 手臂：`arm_swing_deg` 12→9（肩部摆幅减小），`forearm_base_deg = 8`（肘部常驻微屈），`forearm_bend_deg` 8→26（前摆时屈肘，手收到身前），`arm_phase_lag = 0.06`（手臂略滞后于腿），`hand_follow = 0.35`（手腕随前臂），`far_arm_scale = 0.55`（远侧手臂在身体后方，摆幅减小，否则前摆时像向前伸手）；前臂限位 −30° → −45°。
- 同时修正上一轮引入的 IK 不连续：`exact_within` 在静止距离之上改为 C1 连续渐近全长（原交界处髋踝距突降 ~0.45 px，近直腿膝角在趾离地时一帧跳 12°）。

**结果：** 120 px/s 时大腿平均前倾 −10° → 约 −7°（落点在骨盆竖线附近），肘部全程弯曲 8–34°。round2 8/8（膝角速度最大 19.6 rad/s，含 200 px/s 与 120 Hz）、自然度 OK、旧步态 28/28、G6 49/49、App 12/12；G5 行走：漂移 0.0、无穿地、速度 119.8、膝角速度 ≤ 10.9 rad/s（比上一版更低）。证据：`spikes/_qa/side_gait_review2/legs_arms_before_after.png`、`arms_cycle_after.png`。
