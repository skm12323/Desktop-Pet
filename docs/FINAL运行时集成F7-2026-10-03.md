# FINAL F7 运行时集成

2026-10-03。FINAL 已接入应用的“正面归位 → 转身 → 长裙侧走 → 收脚停步 → 转回正面”流程。

## 行为与配置

- `final_locomotion` 默认 `side_rig`，独立于 `adult_locomotion`。旧配置缺少此项时采用默认值；设为 `legacy` 可回退。配置示例与校验均已更新。
- 应用根据当前阶段加载 `assets/rig_adult_walk_v1` 或 `assets/rig_final_walk_v1`。缺少骨骼、帧包或任一片段帧时恢复旧展示路径；画布不属于当前阶段的包会被拒绝。
- 步态尺度按当前窗口与侧身源画布的实际缩放比例计算，FINAL 使用1024×1824，ADULT使用960×1696。阶段切换引起的窗口尺寸变化在下一帧更新；正在行走的会话保留其既定尺度，避免中途跳变。
- 十种情绪在行走会话期间共用中性蒙皮骨骼；neglected 统一使用去饱和配色。停步转回后恢复最新情绪，行走途中换情绪不会切断骨骼。拖拽、离地或动作帧会立即中断并恢复当前表情。
- 阶段切换先撤销旧会话和延迟启用请求，清空片段挂载与侧身资产路径，再装配新的阶段。旧侧身数学核随路径清空释放。
- 320默认窗口选256高转身帧包；两个方向独立解码预算约4.16 MB/条。大窗口沿用512/1024档选择及缺档回退。
