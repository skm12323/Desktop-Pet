# ADULT 连续视角转身与自然横向行走执行计划

日期：2026-09-25。状态：执行计划，尚未开始生成转身素材或实现新的行走。以下数值均为项目拟定验收目标。

## 1. 目标与范围

交付：ADULT 从当前正面放松站姿自然转向约 45°行走朝向，沿桌面左右行走，停止后收步；支持转回正面、途中反向以及拖拽/落地中断。

技术路线：AI 参考图编辑制作关键视角 → 分层校正 → 共用拓扑与纹理配准 → 连续视角形变 → 世界空间接触约束和双腿 IK → 次级运动。

先交付右向验证版：正面、右转约 20°、右转约 45°。随后补齐左转约 20°、左转约 45°。角度是制作控制点，不代表 AI 已生成精确的三维旋转。左侧在定稿前独立检查非对称饰品、刘海与尾巴，整图镜像只用于临时验证。

首版覆盖 `healthy_neutral` 蒙皮路径。其他心情/分支沿用原显示方式，但切入切出时必须正确清理接触和朝向状态。完整 90°侧面、背面、跑步不列入本轮交付。

## 4. G0：坐标和资产契约先冻结

1. 保持源画布 960×1696，x 向右、y 向下；所有记录明确区分源图像素、逻辑显示像素、设备像素和世界坐标。
2. 从当前已修复姿态导出正面制作参考；bind pose、放松姿态偏置和显示脚底偏移分开记录。转身资产若烘焙了放松姿态，运行期不能再重复叠加旧的手臂偏置。
3. 每个关键视角记录骨盆、肩、肘、腕、髋、膝、踝和鞋底标记。脚底标记至少有 sole/heel/forefoot，标记不是新增变形骨。
4. 为同一部件固定顶点 ID、顶点数量和三角索引；各视角分别记录位置、纹理对应、可见性与关节投影。
5. 明确零姿态不变量：在任意视角，步态骨骼增量为零时，渲染结果应等于该视角的定稿关键形态，不能被再次旋转或拉伸。
6. 外部接口预定新增：`desired_facing` 表示行进意图；`view_yaw` 表示连续可见朝向；真实窗口根位移、地面、显示变换、时间戳传入步态求解器。身体左右脚使用固定身份，不随镜像互换名称。

建议资产结构：

```text
assets/rig_adult_turn_v1/
  baseline/                  # 当前生产资产副本
  baseline.json              # 源哈希、环境、原有偏置
  references/                # 定稿关键视角
  candidates/right45/        # 候选与生成记录；其他角度同样管理
  layers/                    # 共用纹理与新显露区域补片
  annotations/               # landmarks、接触点、遮挡与视角标记
  spec.json                  # 骨架、视角、步态配置
  mesh/mesh_data.json         # 固定拓扑、权重
  mesh/view_keyforms.json     # 各视角顶点、关节、纹理配准/补片规则
```

`view_keyforms.json` 为拟新增格式。其解析、形状检查和错误回退必须与写入工具同一阶段实现，不能只保存 JSON 就视为引擎已支持。

## 5. G1：AI 生成操作规程

先只做右侧两个新视角。每个视角第一轮生成 4 个候选，结构正确但局部错误时使用局部重绘；第二轮仍没有合格候选，就改用简单 3D 代理的轮廓/深度引导，或校正关键图，不继续盲目增加随机种子。

生成记录必须包括原始参考哈希、所有输入参考、模型和工作流版本、seed、提示词、采样参数、输出文件名及选用原因。同 seed 有利于复现，不代表角色一致性已成立。

右45°参考指令的内容模板：

> 使用正面参考中的同一个角色，保持脸型、发色、头饰、耳鳍、服饰、鲸鱼图案、金线、袜鞋和尾巴设计。角色原地转为朝画面右侧的三分之四视角，保持与参考相同的放松站姿和表情，不迈步。双脚接触同一水平地面，人物大小、镜头高度、光照和画布比例保持一致。合理补全新显露的身体与服装部分，保持非对称饰品的身体归属。输出完整角色，不裁切发梢、尾巴或鞋底。

右20°输入同时包含正面和定稿右45°，指令明确“介于两张参考之间的轻微侧转”。原始正面始终保留，避免连续使用上一张生成图导致身份漂移。

执行要点：

- 第一批制作参考允许干净纯色背景；拆层阶段再检查真正 alpha，不能把提示词中的 transparent 当作实际透明通道。
- 图像配准只校正画布位置和整体尺度，不能通过非均匀拉伸把错误脸型硬压成正确比例。
- 身高可在脚底对齐后检查约 ±2% 的偏差；脸宽、肩宽不能按此阈值强制一致，因为正常透视会改变它们。
- 鲸鱼图案、纽扣、金线和蝴蝶结优先复用原纹理并随部件变形。AI 图作为视角结构参考，减少逐视角重新绘制细节导致的闪烁。
- 候选验证通过后才拆层，拆完一套后再做轮廓和接缝复核。

新增生成入口建议命名为 `tools/generate_adult_turn_views.py`。先实现可配置的参考图、输出目录、角度标签和 seed，再执行生成；启动时检查本机 ComfyUI 实际节点输入，不能假设原有单图工作流已经支持多图连接。

## 6. G2/G3：转身实现细节

### 纹理与几何

首选“主要固定纹理 + 新显露区域补片”。AI 定稿用于指导网格关键形态，脸部侧缘、远侧肩、裙侧等原图不可见的区域使用补片。补片沿遮挡边界显露，限制在需要变化的区域。

当某一部件必须使用多视角纹理时，先配准到同一语义网格，再实现相同几何上的纹理混合；这一分支需要额外材质/预处理实现。禁止直接给整张角色图做交叉淡化，也不能在不同纹理岛之间直接插值 UV。

现有网格生成器对每张图独立采样，会产生不同顶点。新增配准工具从规范网格出发，只改变顶点位置或添加共同的细分，再把所有视角一起更新。

### 视角绑定与求解顺序

当前 LBS 使用固定 bind/inverse-bind。新增视角形变时，肩、髋、膝等绑定支点也要更新：

```text
连续视角参数
  → 当前视角的静止网格 + 静止关节 + face/occlusion 参数
  → 当前视角 bind/inverse-bind
  → 放松姿态偏置（若未烘焙）
  → 骨盆与腿部接触求解
  → FK/LBS
  → 最终屏幕变换
```

首版先在固定45°视角使用该投影下的腿长求解行走，再处理转身期间投影长度变化。不能要求正面和45°的二维腿长数值完全相等。每个视角内部仍保持解算腿长，不用任意缩放小腿来掩盖不可达目标。

头部测试最先覆盖脸/眼/刘海遮挡。眨眼与注视随后组合验收：原有 blink_delta、瞳孔范围和眼眶中心也需随视角配准，不能永远使用正面参数。

### 遮挡与全身转动

远侧手臂、头发和尾巴采用分层拆分/遮罩；需要切换层顺序时，应发生在对应边界已经被遮住的位置。不能整只手臂突然跳到裙子后面。

全身转身起调时长 0.25–0.35 秒：视线/头部先动，肩胸随后，骨盆跟进；头发和尾巴最后再加滞后。此时脚也必须有接触计划，可以小幅移重心、以前掌为支点转动，必要时移动非承重脚，不将双脚机械钉住来强扭身体。

## 7. G4/G5：行走与状态机

先用现有髋—膝—踝完成固定朝向 IK，完成鞋和膝权重后再加脚尖骨。双锁骨与衣物关节按实际缺陷增补，不把“达到55骨”作为验收目标。

初始调试参数：256高显示下先测 45/75/120 px/s，频率初值 1.1–1.5 周期/秒，抬脚 3–5 px，支撑/摆动比 60/40。它们是待调组合；使用 `每周期根位移=速度/周期频率` 约束步长，不独立随意设定。超出关节可达范围时限制自然步行速度；当前600 px/s跟随不强行套用步行，行为层需减速或进入另行定义的快速移动路径。

脚底求解：锁定世界空间的活动接触标记 → 用最终显示变换求模型目标 → 按鞋角反推踝位置 → 调骨盆 → 双骨 IK → 脚踝反向补偿。提踵时接触由 heel/sole 转到 forefoot，不能继续要求整个鞋底刚性固定。

时间与渲染前置：

- 呈现器用单调时钟实际 dt，不再固定推进33 ms。
- 根窗口位置与脚姿态使用同一帧数据提交；行为和动画的不同定时器不能各自使用不同帧的根位置。
- 接地 ADULT 的最终脚位置不能再被 QML 的整体 bob/rotation 或 bodyAngle 90ms补间二次移动。身体起伏在接触解算之前完成。
- `desired_facing` 进入转向规划，ADULT新路径不触发旧的即时整体镜像；旧阶段继续保留原行为。

状态次序：

```text
IdleFront → TurnToWalk → Start → Walk → Stop → IdleSide
IdleSide → TurnFront → IdleFront
Walk → Brake → TurnToOtherSide → Start
任意地面状态 → Drag/Airborne → Landing → 重新建立接触
```

起步先确定支撑脚，停止时把摆动脚收回合理落点。行为层已停止时，收步按新根位置重算。转向中收到反向指令，从当前姿态继续规划，不重置成关键图。figure/stage切换或资产加载失败时统一释放旧接触和视角状态，回退到原显示路径。

## 8. 关键验收标准

统一单位：下表像素均为256高窗口中的**逻辑显示像素**；384/512按比例换算。接触数据从蒙皮后顶点/标记经过完整显示变换得到，同时记录窗口世界位置。关闭次级运动的测试与完整效果测试分开保存，不能混用结果。

| 项目 | 硬门槛 / 视觉门槛 | 测量方法 |
| --- | --- | --- |
| 角色一致性 | 无变脸、图案重画闪烁、纽扣/饰品数量变化或身体归属换边 | 关键视角并排看；256实际尺寸、原始尺寸局部检查 |
| 共同拓扑 | 同一部件所有视角顶点ID/数量/三角索引一致，UV/骨骼引用有效，权重和误差≤1e−4 | 数据校验；独立生成的网格不得直接通过 |
| 网格连续性 | 每个视角区间至少采样101点，正常可见三角形无翻面，无NaN；设计的隐藏/退化区单独标记 | 有向面积、可见性与数值检查；不能把背面消失误判为普通网格错误 |
| 关键点拼接 | 静止骨骼下，内部分段边界两侧归一化参数±1e−4的同名标记位移差≤0.2 px；曲线至少C1连续 | 检查关键视角边界，另看速度曲线与1/4速回放 |
| 纹理与遮挡 | 脸、眼、鲸鱼图案、裙缘、肩口、尾根无重复边、透明裂缝或突然换层 | 正常速度、1/4速、逐帧三种检查；数据通过不能替代目视 |
| 转身接触 | 每个固定支点阶段的世界漂移≤0.5 px，穿地≤0.5 px | 分别跟踪sole/heel/forefoot；支点转换按计划记录，不将提踵误判为滑动 |
| 行走接触 | 单次固定接触阶段累计漂移≤0.5 px，穿地≤0.5 px；非承重脚离地间隙有效 | 含真实窗口移动、groundShift、镜像/视角、LBS的完整链路 |
| 关节与衣物 | 无膝翻折、明显鞋面扭曲、裙口/肩口裂缝；固定视角腿长误差≤0.1% | 求解数据与最终图像联合检查；跨视角二维投影长度允许变化 |
| 往返与打断 | 左右各重复20次，无瞬时镜像；同一中立参数关键标记回位差≤0.5 px | 关闭次级运动测回位；另测转身中反向、停步、拖起 |
| 时间一致性 | 同一世界轨迹和时间戳下，30/60Hz及不均匀dt结果位置差≤1 px，接触事件时间差≤1个30Hz帧 | 在接触事件边界使用时间容差，不要求相邻离散帧状态绝对相同 |
| 性能 | 目标机器活动60Hz测试中，提交/呈现帧间隔P95≤20ms；暂停/卡顿另报；无持续帧资源增长 | 单宠物完整Qt路径记录60秒，另做10分钟循环；抓帧导出不参与性能计时 |
| 回归 | 原正面站姿保留；YOUNG↔ADULT、其他figure、拖拽/下落/落地及资产缺失回退正常 | 使用现有脚本并新增针对新状态的断言，不能只断言骨骼数量和角度非零 |

视觉复核不能用单一图像相似度代替：正常透视会改变轮廓和五官间距，相似度高也可能只是几乎没有转身。

测试矩阵：左右方向 × 256/384/512 × 浅/深背景；覆盖系统当前DPI及可用的另一档DPI；起步、稳态、慢停、急停、反向、碰边、拖起落地、阶段与figure切换。主矩阵先自动采样，脸/肩/裙/尾的关键问题再逐帧查看。
